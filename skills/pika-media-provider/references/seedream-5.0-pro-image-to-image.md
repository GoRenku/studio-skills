# Seedream 5.0 Pro Image Editing

Official operation specification:
https://dev.pika.art/llms/bytedance/seedream-5.0-pro/image-to-image

Use when one or more deliberately chosen images must be edited, combined, or
used as visual references. Preserve their final request order. Give every local
marker a meaningful review label describing its intended role, then state in
the prompt what must remain stable and what may change.

Inspect the live schema immediately before authoring the request and place
markers only in its exact native media field. This guide defines no prompt
token, copied field inventory, default, bound, output count, resolution option,
or price.
