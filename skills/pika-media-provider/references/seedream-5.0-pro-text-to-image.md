# Seedream 5.0 Pro Text To Image

Official operation specification:
https://dev.pika.art/llms/bytedance/seedream-5.0-pro/text-to-image

Use for a new image created from text without source images. Write the prompt
as a concrete visual brief: subject, composition, environment, light, palette,
materials, lens or image-making language, and exclusions that matter to the
request. Keep the prompt opaque and preserve the user's creative direction.

Inspect the live schema immediately before authoring the request. Do not copy
fields, defaults, bounds, output counts, resolution options, or prices from this
guide. If a source image is required, select the indexed image-editing operation
instead of adding an invented image field here.
