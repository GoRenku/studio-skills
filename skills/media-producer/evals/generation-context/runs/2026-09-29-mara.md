## Regression lessons and eval coverage

1. Aggregate output limits can hide a briefing even when each nested command's
   limit is large enough. Keep large reads separate and recover from first-call
   capture. The new controlled cases cover both initial batching and clipped
   output recovery.
2. Candidates contain identities; structured consumers need the top-level
   inventory. Keep its fixture integrity check alongside format-choice cases.
3. Existing authored design guidance can conflict with the current requested
   layout. The agent preserves facts and makes the creative choice explicitly;
   runtime must not filter the design.
4. Printed height alone does not prove scale. Review endpoint alignment and
   interval spacing. The first two images above are negative visual QA examples;
   the third is a positive endpoint-alignment example, not a perfect accessory
   continuity ground truth.
5. The Lookbook fixture is only 3,948 bytes. A 4 KiB cutoff would not exercise
   truncation there; controlled large-output variants now use a 1 KiB limit.

For a future blind visual QA trial, show each image separately with the current
character-sheet criteria and ask the agent to assess it. Do not expose this
table or identify which attempt it is. Score whether it catches inaccurate
numeric spacing without falsely claiming the entire workflow failed. No
independent visual judge or blind multi-purpose agent trials ran in this turn.
