# Media Producer Samples

These are representative temporary review documents, not purpose definitions,
provider schemas, or durable Project records. Read the deterministic briefing
for the real target before adapting one:

```bash
renku generation context --purpose <purpose> --target <target> --json
```

The briefing stays outside the review document. Its suggestions are advisory;
the agent may ignore, supplement, or replace them. After choosing a provider,
model, input mode, and exact files, read the provider's current operation facts
and author the native `request` from those facts.

- `image-review.json` shows one Engines image request.
- `image-with-reference-review.json` shows one native local-file marker.
- `codex-image-review.json` shows the same envelope for the built-in image lane.
- `audio-review.json` shows one Engines audio request.
- `shot-plan-video/video-review.json` shows one Engines video request.
- `scene-storyboard-sheet-import.json` is a focused attachment document, not a
  generation review document.

Do not copy optional fields from a sample merely because they exist here. Live
provider validation remains authoritative.
