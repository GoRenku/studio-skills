# Prop Sheet Board Design

Design the board for the exact production questions supplied by Prop facts and
active Prop Design. Useful studies may include dominant silhouette, orthogonal
or handling views, construction/function, materials and wear, human scale,
state variants, and continuity-critical markings.

These are agent-owned creative choices, not a runtime schema. Do not require a
fixed panel count, labels, angles, diagrams, readable text, or semantic image
validation. Inspect the returned image as one opaque artifact and revise only
through the user/agent review loop.

Keep the same physical Prop identity across included studies. Exclude unrelated
characters, locations, alternate objects, UI, watermarks, and decorative copy
unless the authored direction explicitly asks for them.
