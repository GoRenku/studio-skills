# Z-Image Turbo Prompt Guide

Use Z-Image Turbo for fast text-to-image work. Fal.ai and WaveSpeed also publish
image-to-image routes for edits; check the selected route's live schema for its
required source image and edit-strength controls.

## Prompt Guidance

- Describe subject, action, setting, composition, lighting, palette, materials,
  and visual finish in direct natural language.
- State framing and aspect-ratio-sensitive composition when it affects the
  creative result.
- Put required visible text and placement in the prompt.
- Keep a simple request compact; do not inflate it into a generic template.
- On an editing route, state the requested change and the source image features
  that should remain. On a text-only route, do not imply a source image exists.
