# Z-Image Turbo Prompt Guide

Use Z-Image Turbo for fast text-to-image work when no source image is required.

## Prompt Guidance

- Describe subject, action, setting, composition, lighting, palette, materials,
  and visual finish in direct natural language.
- State framing and aspect-ratio-sensitive composition when it affects the
  creative result.
- Put required visible text and placement in the prompt.
- Keep a simple request compact; do not inflate it into a generic template.
- Do not describe unavailable reference images or source-preserving edits.

## Provenance

Recovered from the Z-Image Turbo route guidance introduced with the provider
architecture. Current provider parameters remain owned by the live schema.
