# MiniMax H3 Image Highspeed

Read the shared [H3 Image prompt guide](minimax-h3-image.md) for realism,
casting layouts, identity preservation and reference composition. It also
owns the Highspeed edit route's Codex panel declaration.

Highspeed is a separately selectable Fal.ai option. Use
`minimax/h3-image/highspeed/text-to-image` without references and
`minimax/h3-image/highspeed/edit` for identity-led casting or editing.
Keep the variant confirmed by the casting round when mapping between those
operations. The Default Model List supplies all three casting detail levels.

For text-only casting, write the complete face-and-full-figure brief. Keep
`enable_prompt_expansion` at its default unless the director chooses verbatim
prompting.
For reference-led casting, cite the identity image as `Image 1` and state
which features remain fixed. The inspected edit schema has no expansion switch.
These recommendations share the source basis documented in the main guide.

Fal's Highspeed portrait example demonstrates a natural-language description
of skin texture, clothing, framing and motivated light. Its style-edit example
separates preserved likeness and pose from the requested rendering change.
Use those principles while retaining the casting workflow's neutral light and
backdrop. Research and schema inspection were completed 2026-11-10.
[Portrait example](https://fal.ai/models/minimax/h3-image/highspeed/text-to-image)
and [edit example](https://fal.ai/models/minimax/h3-image/highspeed/edit).
