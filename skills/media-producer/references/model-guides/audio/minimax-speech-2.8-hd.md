# MiniMax Speech 2.8 HD Prompt Guide

Preserve the exact spoken text and deliberately selected voice. Use supported
performance controls only when they serve the requested delivery.

- Keep language, names, numbers, and quoted dialogue exact.
- Describe emotion and speaking style without stacking contradictory labels.
- Choose speed, pitch, volume, and language deliberately rather than copying
  defaults into the request.
- Treat a system voice or exact provider voice id as the speaker identity.
- Use composition or lipsync for exact synchronization requirements.

## Provenance

Recovered from the MiniMax Speech 2.8 HD route guidance introduced with the
provider architecture. The live provider schema owns current fields and values.
